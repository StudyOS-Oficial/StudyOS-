STUDYOS V5 · PUBLICACIÓN EN GITHUB PAGES

1. Descomprime el ZIP público y sube todos los archivos directamente a la raíz de tu repositorio StudyOS-.
2. index.html, leer.html, lecturas.js, pagos.js y las imágenes deben estar al mismo nivel.
3. El lector solo contiene los capítulos gratuitos de las tres guías. Ningún PDF completo premium se publica aquí.
4. El archivo pagos.js mantiene enabled:false. NO actives cobros hasta tener verificación de pagos y entrega privada probada.
5. Los PDF de las ediciones ampliadas están en el ZIP privado. NO los subas a GitHub ni a GitHub Pages.
6. Revisa y elimina del repositorio público cualquier PDF premium subido previamente; borrar el enlace no borra una copia pública.
7. Acceso a StudyOS+ exige definir duración, condiciones y protección técnica.
8. El aviso de privacidad, términos y desistimiento del contenido digital deben revisarse antes de vender.
